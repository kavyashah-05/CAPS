
# C.A.P.S. — Campus Placement & Academic System

## 1. Project Overview

C.A.P.S. is a full-stack web application designed to help a college Training and Placement Cell manage placement drives, student applications, recruitment rounds, and placement records.

## 2. Objectives

- Centralize placement-related information.
- Simplify student eligibility checking and shortlisting.
- Track recruitment rounds and selection results.
- Manage student documents securely.
- Provide useful placement reports and analytics.

## 3. User Roles

### Admin
Manages students, companies, placement drives, eligibility rules, recruitment rounds, documents, and reports.

### Student
Views placement drives, checks eligibility, applies for opportunities, manages documents, and tracks application progress.

## 4. Planned Technology Stack

- Frontend: HTML, CSS, JavaScript
- Styling: Tailwind CSS, if useful
- Backend: Node.js and Express
- Database: PostgreSQL through Supabase
- Document Storage: Supabase Storage
- Version Control: Git and GitHub

## 5. Development Approach

The application will be developed incrementally. Each milestone will include appropriate documentation, testing, and meaningful Git commits.

## 6. Project Status

Current phase: Repository setup and project planning.
